# Installation

Install Agent Code from PyPI with the standard pip command:

```bash
pip install agent-code
```

No repository checkout, shell installer, or separate Agent Code system-dependency command is required for the Python package.

Launch the CustomTkinter desktop application with `agent-code`, or use `agent-code tui` on a headless machine. The authenticated browser interface is separate: start it with `agent-code server`.

Upgrade with:

```bash
pip install --upgrade agent-code
```
